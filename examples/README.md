# Synthetic BiLSTM coding demonstration

Install PyTorch, then run:

```bash
python examples/synthetic_bilstm_demo.py
```

Uses entirely synthetic variable-length sequences and labels. Demonstrates padded sequences, `pack_padded_sequence`, a bidirectional LSTM and a small training loop. This is **illustrative newly prepared code**, not the original Clin2Path research implementation and not validation of model performance in ROS/MAP participants.

The script was tested locally with synthetic data before upload.
